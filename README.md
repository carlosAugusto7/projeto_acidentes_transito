# 🚗 Análise e Visualização de Acidentes de Trânsito no Brasil (2015–2024)

## 📌 Descrição
Este repositório contém o projeto de análise exploratória e dashboard interativo desenvolvido para a disciplina de **Linguagem de Programação — Análise e Visualização de Dados com Python**.

## 🛠️ Tecnologias Utilizadas
* Python (Pandas, NumPy, Matplotlib, Seaborn, Plotly)
* Banco de Dados Relacional (SQLite)
* Streamlit (Dashboard Interativo)
* HTML5/CSS3 (Landing Page no GitHub Pages)
