Análise de Acidentes de Trânsito no Brasil (2015–2024)

Projeto de Linguagem de Programação — Análise e Visualização de Dados com Python

Apresentação do Projeto

Aplicação analítica desenvolvida para estudar a evolução temporal, o impacto regional, os fatores climáticos e os níveis de gravidade dos acidentes de trânsito no Brasil.

💻 Repositório GitHub 🚀 Dashboard Streamlit

Funcionalidades Desenvolvidas

🗄️ Persistência SQL

Integração com banco de dados SQLite para consultas otimizadas e organizadas.

📊 Dashboard Interativo

Painel em Streamlit com Plotly, filtros múltiplos dinâmicos e cartões de KPIs.

📈 Análise de Tendências

Séries temporais e mapeamento de horários e condições de risco.
